## Best friend: what Jive takes off your plate

<CardGrid>
  <Card title="No CI to write" icon="setting">
    Extend an abstract and your package has a full pipeline: build, test, deploy. The abstract also owns the config
    schema your editor completes, and the scaffold. <Badge text="Built" variant="success" />
  </Card>
  <Card title="Nothing to create by hand" icon="add-document">
    Each deploy makes sure what it deploys to exists: the npm package, the repository, the DNS record. You never click
    through a dashboard first. <Badge text="Built for npm packages" variant="success" />
  </Card>
  <Card title="No keys on your machine" icon="approve-check">
    Sign in once with a passkey. Jive's server holds your SSH key and signs your commits and pushes, so no machine
    keeps a private key. <Badge text="Built" variant="success" />
  </Card>
  <Card title="No secrets in CI" icon="warning">
    A pipeline signs in with its own GitHub identity and acts through credentials Jive holds, so no long-lived tokens
    sit in your repository settings. <Badge text="Sign-in built; tokens still stored" variant="caution" />
  </Card>
  <Card title="Many repos, one workspace" icon="seti:git">
    Keep every package in its own repository and still work in one checkout, signing and pushing the same way
    everywhere. <Badge text="Built" variant="success" />
  </Card>
  <Card title="Agents that don't need your laptop" icon="rocket">
    Agentic workflows run on cloud compute with a session Jive gives them, so work keeps going while your laptop is
    closed. <Badge text="Planned" variant="note" />
  </Card>
</CardGrid>

## Worst enemy: a business that runs itself

Everything above is designed to compose. Agentic workflows are packages built from steps, and workforces are built from workflows.
Resource providers give every one of them the same way to reach the outside world. A software factory is one
workforce, binary decompilation another, and a business and its operations a third. Put enough of them together and
nothing is left for a developer to do.

## Built on a few ideas

<CardGrid>
  <Card title="Everything is a package" icon="puzzle">
    Libraries, apps, servers, resource providers and agentic workflows are all npm packages. Even each kind of package
    is a package, an abstract, so anyone can publish a new kind.
  </Card>
  <Card title="Packages compose" icon="random">
    A package extends an abstract for how it ships, and declares the resources it needs instead of sharing code.
    Working together doesn't require a monorepo.
  </Card>
  <Card title="Workflows, not prompts" icon="list-format">
    An agentic workflow is code: each step is deterministic or one bounded agent call, retried on failure and measured.
    What must happen is enforced, not hoped for.
  </Card>
  <Card title="Jive holds the credentials" icon="star">
    People, pipelines and agents hold only a session. Every key and token stays with Jive, behind one API.
  </Card>
</CardGrid>
